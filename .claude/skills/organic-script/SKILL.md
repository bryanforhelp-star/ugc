# Organic UGC Script

Write a script for: $ARGUMENTS

## The whole skill, in 6 rules

1. **Hook in the first 2 seconds.** A specific claim, confession, or reveal. Not *"today I want to talk about..."*  Yes *"I've lived in Bali 18 months and only know two Indonesian words."*

2. **Brand mentioned ONCE, casually.** Never *"X is the best [category]."* Yes *"I've been using X for 12 days."* The brand is part of the storyteller's life, not the subject of the video.

3. **No hard CTA.** No *"search," "click," "download," "save this," "share this."* End on a vibe, a question, or an unresolved beat. The bio and caption do the conversion.

4. **Specifics that prove a real person made this.** A friend's name. An exact timeframe. The one moment that mattered. Generics sound like a brand.

5. **Native rhythm.** Sentence fragments. Vary length. Talk like a person, not a copywriter.

6. **15–45 seconds.** Most land 25–35.

## Pick one format

- **Confession** — *"I've [embarrassing thing] and I still [haven't fixed it]."*
- **POV** — *"POV: [specific micro-moment]."*
- **Cultural insight** — *"If [audience] [does this thing], here's what's actually happening."*
- **Story** — *"Things I learned the hard way before [moment]."*
- **Mini-lesson with personality** — *"[Topic] of the day: [specific thing]."*
- **Hot take** — *"Hot take: [contrarian claim]."*
- **Stitch / response** — react to existing content.

## Avoid

- *"Stop scrolling," "imagine if," "what if I told you"*
- *"Save this," "share with someone who," "tag a friend"*
- Listicle ads (*"X things you need before Y"*) — unless framed as personal story
- Founder-explains-product talking head
- *"Top 5,"* *"Best [X],"* *"The ultimate guide"*
- Voiceover + B-roll testimonial style (feels like a Meta ad)
- Hook that's a setup instead of a reveal

## Two checks before shipping

- **Read it out loud.** If it doesn't sound like how you'd actually tell a friend — rewrite.
- **Cover the brand name.** Does the video still deliver value as a standalone piece? If no, it's an ad. Rewrite.

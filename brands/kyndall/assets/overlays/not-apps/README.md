# not-apps overlays

UI mockup overlays for the "most useful things I build aren't apps" reel.

**Script:** `scripts/2026-07/not-apps.md`  
**Keyword:** `APPS`  
**Source video:** local export (not in repo)

## Style lock

- Blue accent only (`#3B82F6`). No pink.
- Tech brands: Cursor, Claude, Replit, Linear.
- 1536 × 1024 PNG. Scale to ~40% in a 9:16 timeline.

# Arcads upload

Give Arcads these files. The logo is the PNG/SVG, not the type sitting on a generated can. Image models warp letters. This wordmark is Helvetica Neue Bold.

## 0. Paste the site

`https://bykyndall.com/anyway`

Fake product page. Arcads can scrape it for brand, product, and photos.

## 1. Paste the form

From `arcads-form.md` in this folder.

## 2. Upload logo first

Use `logo-red-transparent.png`. Fallback: `logo-red-on-white.png`.

The mark is two lines, centered, lowercase:

```
any
way
```

Cherry red `#E4002B`. Never green type. Never three lines. Never `an / ny / wa`.

## 3. Then product

1. `product-packshot.png` (white background)
2. `product-fridge.png` (bodega cooler, cigs above and below)
3. `product-hero.png` (single can, flash)
4. `lifestyle-haul.png` (four cans in hand)
5. `lifestyle-nyc.png` (grungy NYC, wired headphones)

## 4. Brand board

`brand-kit.png` is the one-pager: wordmark, colors, type lock, product, lifestyle.

## Do not

- pink, blobs, mascots, leaves
- wellness / pilates / cafe window light
- extra flavors, cherries, "MATCHA CHERRY"
- redraw the wordmark from a photo
